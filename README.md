# Thème Digima

Thème blocs (FSE) de www.digima.be, construit sur le design system Digima. Voir CLAUDE.md pour l’architecture et l’état du projet.

- Charte : bleu nuit `#0D2A3A`, vert accent `#C4E86B`, bleu acier `#3F7398`, typo DM Sans (embarquée).
- Requiert WordPress 6.9+ et PHP 8.0+.

Pour tester la synchro : modifier `Version` dans `style.css` ou le texte de `parts/footer.html`, pousser, et vérifier que le site se met à jour.
